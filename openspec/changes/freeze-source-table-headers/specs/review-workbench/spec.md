## ADDED Requirements

### Requirement: 原始病历数据表列名首行滚动冻结

工作台展示原始病历的两处滚动容器 —「原始病历」modal (`.modal-body`) 与右侧「原文对照」面板 (`.source-body`,二者共用 `.src-scope` 标记)— 内的数据表 (`table.data-table`),其列名首行 (`thead`) 在容器纵向滚动时 SHALL 冻结(sticky)在滚动视口顶部,使专家核对长表格时随时可见列含义。

该行为 SHALL 通过纯 CSS 实现,不修改表格渲染逻辑、tab 切换、搜索或命中高亮的既有行为。段标题 (`.lab-section-head`) 与文书桶标题 (`summary.note-bucket-head`) 不在冻结范围内,随内容滚走。

#### Scenario: 费用 tab 列名首行冻结

- **WHEN** 用户在 modal 或原文对照面板的「费用」tab 内向下滚动
- **THEN** 列名首行(时间 / 项目 / 规格 / 数量 / 单价 / 合计 / 类别)冻结于滚动视口顶部,始终可见

#### Scenario: 检验记录 tab 两段表头接力冻结

- **WHEN** 用户在「检验记录」tab 内从化验段滚动进入检查段
- **THEN** 化验表头(时间 / 项目 / 结果 / 参考 / 标志 / 科室)在化验段内冻结;滚入检查段后由检查表头(时间 / 检查 / 结论·描述 / 科室)接替冻结

#### Scenario: 文书 tab 桶内表头冻结、桶间接力

- **WHEN** 用户在「文书」tab 内于某折叠桶范围内向下滚动
- **THEN** 该桶的列名首行(时间 / 阶段 / 子阶段 / 内容)在该桶垂直区间内冻结;滚出该桶后由下一桶的列名首行接替冻结

#### Scenario: 冻结表头保留下边框分隔线

- **WHEN** 列名首行处于冻结状态(已与下方内容滚动错开)
- **THEN** 表头底部分隔线仍可见且背景不透明,下方数据行不透出表头

#### Scenario: 搜索跳转不被冻结表头遮挡

- **WHEN** 用户用搜索(Ctrl+F)跳转到某命中行
- **THEN** 命中行滚动定位时在冻结表头下方留出表头高度,命中行不被表头遮挡

## Context

用户明确选择gnome-243。该分支HEAD=8645a2d，已交付LIS包manifest约束10个运行文件和4个前置依赖；结算包记录更早覆盖关系。现场截图确认安装成功，但2026-09-20只读SSH探测无法取得现场文件，需保留UNKNOWN。

## Goals / Non-Goals

Goals：gnome工作树与已交付补丁受控文件逐字一致；测试和维护材料可重现；现场可只读验证；所有相关说明文档一致。

Non-Goals：不改FP8分支，不部署或重启，不变更规则/模型/配置，不以本地一致等同服务器正在运行的一致。

## Decisions

1. 运行源码直接来自已校验SHA的交付files；依赖来自结算包或经摘要匹配的侧栏文件。不重写实现，不重新打包/修改原签名ZIP。
2. 固定发布清单由8645a2d完整包的运行范围摘要叠加已验证热补丁摘要生成；文档和受保护本地配置排除。核验脚本只读期望清单和文件，不调用应用、不访问数据库、不回显环境或患者信息。
3. 输出分别列出热补丁14文件、完整已知发布范围、DEPLOY_COMMIT与Web进程观察。无法访问进程或不能证明已加载代码时保持UNKNOWN；即使磁盘通过也不伪称内存模块逐字核验。
4. 原回归测试回收并在gnome执行；安装器演练所需旧代码夹具归档为受控代码快照，不再依赖临时工作树。保留旧ZIP不可变，维护构建器不能把后续修改静默输出为同名v1。
5. 243/249按历史名称与当前已知院内地址说明，不凭名称断言是两台独立服务器。当前服务、费用、LIS、批跑、EDA、启动与回滚统一到运维入口；历史演示教程停止作为当前操作步骤。
6. AGENTS只保留硬边界和导航，CLAUDE指向AGENTS；历史机制与版本事实归docs。规则库存用命令验证，不手抄旧数字。

## Risks / Trade-offs

- 无院内通道 → 提供只读检查包，现场未回传前实时一致性未知。
- DEPLOY_COMMIT仍是原基线 → 与文件SHA和补丁ID共同解释，不将基线戳当完整版本。
- 用户已有未跟踪资料 → 保留原文件与摘要，不批量add/清理，不改FP8引用。
- 后续版本新增代码 → 不能复用v1标识；需新补丁和独立验收。

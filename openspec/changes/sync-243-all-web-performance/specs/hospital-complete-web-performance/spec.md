## ADDED Requirements
### Requirement: 院内仅同步通用性能
系统 SHALL 保留院内业务行为并提供压缩、费用预处理复用、无白屏导航和详情短期缓存，已有分页/历史减载不得丢失。
#### Scenario: 重复患者访问
- **WHEN** 同标签页60秒内往返患者
- **THEN** 可复用有界快照，审核/事件/401/断线/焦点变化按既定规则失效，旧原文不得串入新患者
#### Scenario: 院内业务兼容
- **WHEN** 上海模式展示患者和原文
- **THEN** 不查询其它患者原文，全局主诊/费用筛选仍隐藏，LIS本次/pending分区及费用命中结果不变
#### Scenario: 传输优化
- **WHEN** 客户端支持GZip
- **THEN** 大HTML压缩且SSE仍未压缩，目标运行环境不兼容时安装前停止

### Requirement: 完整性能补丁保留已安装日期功能
安装器 SHALL 从已安装日期补丁直接升级到v2，并只改9个白名单文件。
#### Scenario: 未安装v1
- **WHEN** 院内文件匹配已交付日期补丁
- **THEN** v2独立安装全部性能改动，不要求先运行v1
#### Scenario: 保留监测账本
- **WHEN** 用户从本包入口恢复监测
- **THEN** 校验新运行文件并保持原context/盐/队列/结果，未知非性能变化仍拒绝
#### Scenario: 未知版本或运行中任务
- **WHEN** 文件混合、被修改、摘要损坏或任务持锁
- **THEN** 停止且不覆盖任何受控文件
#### Scenario: 安装失败和回滚
- **WHEN** 文件写入中途失败或操作者执行回滚
- **THEN** 恢复实际安装前日期版本，配置/数据库/规则/账本保持，回滚前验证全部备份
#### Scenario: 无关进程不可读工作目录
- **WHEN** 同账号进程的命令明确与应用无关，但其cwd读取被系统拒绝
- **THEN** 停止脚本和安装器不访问该cwd，继续核验其它进程；候选应用cwd或进程命令不可读仍须停止

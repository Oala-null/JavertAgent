# Javert 审计经验库 (v0.7, J61556 第一轮批注提炼)

本文档是 LLM 在每条规则裁决前必须核对的 **专家共识知识库** — 把临床医生的判断模式
直接喂给 audit prompt, 减少 LLM 的"较真式"误报 (R153 / R203 / R220 等已观察到的退化).

每次 audit-patient 跑动时, base prompt 会把本文加载进 system context, 让 LLM 跟专家
裁决靠拢. 目标: **wangxin 的 verdict 作为弱监督 ground truth, 让 v1.3 减少 expert=C/I 但 v1.2=V 的退化**.

## 2. 全局共识 (跨规则原则)

### 共识 1 — 肿瘤患者查肿瘤标志物 ≤2 次 = CLEAN

**适用规则**: R153 (AFP), R156 (PSA), R279 (其他标志物), 任何 "肿瘤标志物 / 癌胚抗原 / CA125 / CA19-9 等" 相关规则.

**专家原话**:
- wangxin (5): "肿瘤病人查肿瘤标志物属于正常诊疗行为, 不予认定"
- jiweihui (4): "疑似肿瘤的, 检查一次不被认定为过度"
- zhoulihong (4): "支持「甲胎蛋白测定 AFP」及「甲胎蛋白异质体测定」检查的指征, 建议包括到胸腹腔内器官的恶性肿瘤诊断, 如肺恶性肿瘤、胃恶性肿瘤等, 用以排查肝转移可能"

**LLM 判定流程**:
1. `note_diagnosis` 看是否有**任何**恶性肿瘤诊断 (淋巴瘤/胃肠癌/肺癌/乳癌/甲状腺癌/神经系统肿瘤/已转移恶性肿瘤/继发恶性肿瘤等)
2. `search_lab_results` 看该标志物收费次数 (≤2 次 = 常规筛查)
3. 命中 → **CLEAN**. **不要纠结**"肿瘤类型跟标志物是否字面对应" (淋巴瘤查 AFP 也可以,叫排查肝转移)

**反例 (仍 V)**:
- 完全无肿瘤诊断 + 健康体检 + 查肿瘤标志物 → V
- 同标志物 ≥3 次反复查 + 无明确随访指征 → V

### 共识 2 — 系统性肿瘤累及多脏器 → 多器官评估 = CLEAN

**适用规则**: R278 (内分泌套餐), R279, R131 (心彩超), R155 (细胞因子), 任何"打包套餐"规则.

**专家原话**:
- wangxin (R278): "淋巴瘤有可能累及内分泌系统, 有检查的必要性"
- wangxin (R131): "淋巴瘤有可能累及心血管系统, 且手术病人术前需要排除心肺异常, 故不予认定"
- zhoulihong (R278): "弥漫大B细胞淋巴瘤(中枢、肾上腺、胃部(待定))及颅内占位性病变, 查肾上腺及垂体激素类检查有鉴别诊断的合理性"

**LLM 判定**:
- 患者有 **系统性肿瘤** (淋巴瘤 / 白血病 / 多发转移 / 中枢神经系统肿瘤) → 查多脏器评估 (内分泌 / 心血管 / 神经系统 / 肝肾功能) **CLEAN**
- 局部良性 + 完全无相关指征 + ≥3 类套餐打包 → V

---

### 共识 3 — 重大手术 / 全麻 / 高龄患者术前评估 = CLEAN

**适用规则**: R131 (心彩超), R141/R143/R146 (病情评估), R155 (检查指征).

**专家原话**:
- zhoulihong (R131): "患者在院期间行幕上深部病变切除术, 属于四级手术, 且全麻, 术前行心脏彩超检查评估心脏情况有一定合理性"

**LLM 判定**:
- 四级手术 / 全身麻醉 / 高龄 (≥60 岁) / 重大恶性肿瘤手术 → 术前心评/血生化/凝血 **CLEAN**
- 但: **连续 ≥3 天反复检查同项 + 病程记录 0 症状描述** → V (见共识 7)

---

### 共识 4 — 颅内 / 神经外科 / 脑膜 / 大血管手术 + 控制性降压 = CLEAN

**适用规则**: R220.

**专家原话**:
- wangxin: "违规认定不符合客观逻辑和诊疗常规"

**LLM 判定**:
- 任何 颞叶 / 脑膜 / 脑干 / 颅内 / 颅底 / 脊柱 / 血管外科 / 大型骨科 手术 + 收控制性降压 → **CLEAN** (这是麻醉学常规)
- 浅表外科 (甲状腺 / 皮肤) + 控制性降压 → V (确实不合理)

---

### 共识 5 — 全身麻醉按"次"收费, 1 手术 1 次全麻费 = CLEAN

**适用规则**: R205 (麻醉时长).

**专家原话**:
- wangxin: "全身麻醉按次收费, 患者做了1次手术, 收取1次全身麻醉费用, 没有问题"

**LLM 判定**:
- 手术次数 ≥ 全麻费次数 → **CLEAN** (不论麻醉时长)
- 全麻费次数 > 手术次数 + 无明确时长拆分依据 → V

---

### 共识 6 — 麻醉/影像/检验 ETL 缺失时 → INCONCLUSIVE, **不应直接 V**

**适用规则**: R203 (麻醉记录), R103 (影像), R105 (影像), R015 (虚构服务), R224 (生命体征监测).

**专家原话**:
- wangxin (R203): **"胡扯"** (强烈反对 V)
- wangxin (R015/R103/R105/R224): "未见医嘱单, 未见检查报告单, 病程记录无相关描述" → 都打 I 不是 V
- zhoulihong (R203): "目前所有涉及全身麻醉的都被检出, 原因是未检索到麻醉记录文书, 我们也可以根据【手术记录】及【术后首次病程记录】中"麻醉方法"来判断其收费的真实性, 因以上两份文书是术后记录, 一定程度上可反映术中情况. 病历中除麻醉记录外一般不会描述'诱导药物'、'维持药物'、'苏醒'、'气管插管'等具体麻醉内容"

**LLM 判定**:
- 主 section (麻醉记录 / 影像报告 / 监护记录) 找不到 → **必须** 回退查:
  - `search_notes(section="手术记录")` 看末尾"麻醉医师 + 麻醉时间 + 麻醉方法"
  - `search_notes(section="术后首次病程记录")` 看"麻醉方法"字段
  - `search_examinations(check_type="放射" 或 keyword="部位")` 看影像报告本体
  - `search_lab_results(item_keyword=...)` 看化验结果本体
- 任何回退命中具体执行证据 (麻醉方式 / 报告日期 / lab 结果数值) → **CLEAN**
- 回退**全部 0 命中** + 有手术耗材/麻醉药费 → **INCONCLUSIVE conf 0.5 + etl_warning** (wangxin 标准)
- **不要 V** 除非全部 0 + 无任何手术/检查痕迹 + 多次反复收费

### 共识 7 — "连续检测 ≥3 天 + 病程记录 0 症状" = V

**适用规则**: R141, R143, R146, R155, R160, R161 (病情评估 / 细胞因子 / 心电监护类).

**专家原话**:
- wangxin (R141/R143/R146/R161): "无指征反复复查, 属于过度检查"
- wangxin (R155/R160): "连续检测4天, 病程记录无相关记录, 无法体现合理性"

**LLM 判定**:
- 同检查 ≥3 天连续收费 + `search_notes(keyword=...)` 在常用症状词 ("胸闷"/"气短"/"喘"/"憋"/"胸痛"/"下肢水肿"/"发热"/"咳嗽") 全 0 命中 + 无急症诊断 → **V**
- 单次 / ≤2 天 / 任何手术/急症指征 → CLEAN

---

### 共识 8 — 耗材条码 / 实物证据缺失 → INCONCLUSIVE

**适用规则**: R034 (耗材类), 其他物品类规则.

**专家原话**:
- wangxin: "需要查看耗材粘贴条码"
- jiweihui: "建议条形码"

**LLM 判定**:
- 仅 fee 命中耗材 + 文书无 "植入" / "装入" / "使用 [耗材名]" → **INCONCLUSIVE** conf 0.5 + 标注"需线下核查条码"
- 不要 V (除非有反复多次 + 无任何手术记录)

---

### 共识 9 — 测试与监护合理范围 vs "胡乱拆分收费"

**适用规则**: R026 (心电监测), R224 (生命体征监护).

**专家原话**:
- wangxin (R026): I "心电监测与动态心电图或遥测心电监护不能同时收费 — 规则措辞需改"
- jiweihui (R224): "监测数值分解收取" (V)

**LLM 判定**:
- 不同心电类项目同时收费 → 看规则是否本身合理, 走 INCONCLUSIVE
- 监测项目按数值/参数拆分收费 (如血压收 1 次, 心率收 1 次) → V

## 3. wangxin 风格 cheatsheet

LLM 想象自己是 wangxin 时:

| 情境 | wangxin 判 |
|---|---|
| 肿瘤患者 + 任何标志物检查 ≤2 次 | C (常规诊疗) |
| 系统性肿瘤 + 多器官评估 | C (累及可能性高) |
| 手术患者 + 术前心肺评估 | C (术前常规) |
| 颅内/大手术 + 控制性降压 | C (诊疗常规) |
| 1 手术 1 次全麻费 | C (按次合理) |
| 麻醉记录缺 + 有手术耗材 | I (ETL 缺, 不该 V) |
| 检查报告缺 + 有检查费 | I (ETL 缺, 不该 V) |
| 反复检测同项 ≥3 天 + 无症状 | V (无指征复查) |
| 耗材费 + 无植入证据 | I (查条码) |
| 完全无相关诊断 + 套餐打包 | V (确实违规) |

## 4. 触发器 trigger 机制 (yaml 级具体 knowledge)

每条受影响规则的 yaml `prompt_addon` 末尾会加 **"📌 专家共识触发器"** 段, 列出:
- CLEAN 触发器: 命中即 CLEAN
- INCONCLUSIVE 触发器: 命中即 I
- 反例 (仍 V): 严格反例

LLM 在调用工具收集证据之后, **必须先核对触发器**, 命中则直接给对应 verdict.

🔍 4 类工具盲区: 假指征所在 section 模式

虽然 V 判定都正确, 但关键词全文搜会命中很多假指征 section. 这暴露 search_notes 工具的语义盲区: 它不知道否认/告知/选项这些反向语义.

🔴 盲区 1: 手术风险告知 (常见 60%+ 假指征命中)

手术知情同意书会列出"可能发生的并发症": 心搏骤停 / 休克 / 败血症 / 心衰 / DIC / 心肌梗 等. 这些不是患者真实疾病, 是风险警告.

[手术中或手术后可能发生的并发症 / J13365]
风险告知 "术中、术后出现应激性溃疡、脂肪栓塞、肢体深静脉栓塞、肺栓塞、心肌梗塞、脑血管意外及一些难以预料的并发症, 严重者危及生命."

LLM 用 note_diagnosis() 提取诊断字段时不会看到这一段, 因为这不在诊断子阶段. 但 search_notes(keyword=心肌梗) 会命中.

🟠 盲区 2: 既往史否认 (反向语义)

入院病历的"既往史"段经常这样写: "否认 X, 否认 Y, 否认 Z". 这是反向语义: 患者明确说没有这些疾病.

[既往史 / J18906]
否认 "否认高血压、糖尿病、冠心病、房颤、慢支等其他慢性病史; 否认肝炎、结核、伤寒、血吸虫等传染病史..."

关键词搜 "冠心病" 命中, 但患者明确否认. LLM 通过 note_diagnosis 提取诊断字段时不会看到否认段, 所以不会误判.

🟡 盲区 3: 选项框 / 复印附件

手术核查单 / 病历复印附件中有大量勾选框, 列举各种可能项目, 但都没实际激活.

[患者离开手术室前 / J18906]
选项框 "各种管路: □ 中心静脉通路 □ 动脉通路 □ 气管插管 □ 伤口引流 □ 胃管 □ 尿管 □ 其他
患者: □ 恢复室 □ 病房 □ ICU 病房 □ 急诊 □ 离院"

"ICU 病房" 出现是因为这是个选项框, 不是患者真去了 ICU. 类似的还有"心电图"出现在"病案复印项目列表"中.

🔵 盲区 4: 输血医方告知

输血同意书会列举"可能发生的传染病": 肝炎/艾滋/梅毒 等, 是输血风险, 不是患者疾病.

[医方告知 / J13365]
输血告知 "1. 过敏反应 2. 发热反应 3. 感染肝炎 (乙肝、丙肝等) 4. 感染艾滋病、梅毒 5. 感染疟疾 6. 感染巨细胞病毒"

R153 AFP V 判定中"肝炎"命中就来自这里, 不是患者有肝炎.

结论: LLM 用 note_diagnosis 的智慧

所有模板都让 LLM 优先用 note_diagnosis() 工具拿诊断字段, 而不是 search_notes 全文搜. 这个设计避开了 4 类工具盲区, 是 M2/M5/M6 模板高准确率的核心保障.

下一步建议: 给 search_notes 工具加 section_filter 参数, 默认排除 ["手术风险告知", "既往史否认段", "输血医方告知", "选项核查单"], 让单纯关键词搜也能避开假指征.

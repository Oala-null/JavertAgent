### 2.2 search_fees — 费用检索

**接口** (`src/javert/tools/search_fees.py:21`)

```python
search_fees(patient_id: str, category?: str, keyword?: str) -> str
# category ∈ {手术类, 药品类, 耗材类, 检查类, 其他类}
```

**底层做了什么**

```
1. loader.all_fees() 取全表
2. 按 bah 列模糊匹配 patient_id 过滤本患者
3. 用 _classify(name) 给每条费用打类别标签 (内置关键词字典)
   例如 "CT平扫" → 检查类  (因含 "CT")
        "PET-CT 全身显像" → 检查类  (含 "CT")
        "肿瘤标志物 CEA" → 其他类  (无关键词命中) ← 边界问题
4. 三种模式:
   - 无参 → 5 类各 Top3 摘要 + 总额占比
   - category=X → 该类全部明细按金额降序
   - keyword=X → 全表模糊搜, 显示前 20 条
```

**调用示例 (基于真实 J13365 数据)**

```python
search_fees(patient_id="J13365")
# 返回:
# 费用分类目录 (共 117 项, 总额 ¥32,481.50):
# 【检查类】23 项, 合计 ¥6,840 (21.1%)
#     1. CT平扫(64层以上): ¥200.00
#     2. 脑功能成像: ¥80.00
#     ... 还有 21 项
# 【其他类】89 项, 合计 ¥18,500 (57.0%)
# ...

search_fees(patient_id="J13365", category="检查类")
# 返回 23 条检查明细全列表 (这是 R191/R108/R141 模板用到的关键调用)

search_fees(patient_id="J13365", keyword="报告")
# 返回所有项目名含 "报告" 的费用 — 这是 R191 找"图文报告"重复收费的核心调用
```

**已知局限**

| 问题 | 影响 |
|------|------|
| 分类基于关键词字典, 检验类项目大量进 "其他类" | `category="检查类"` 漏掉很多检验. 模板2 应该结合 keyword 搜 |
| 没有"项目代码"维度, 只看名字 | 串换类 (C) 难判: 同一项目可能名字略不同 |
| 没有"按次/按时长"标识 | E 类 (R074/R227 时长重复) 工具搜不出来 |
| 数据时间精度到天, 没有"同一医嘱内/同一手术内" | A 类某些规则 (比如 R226 静脉营养+配置) 信号弱 |

### 2.3 search_notes — 文书检索

**接口** (`src/javert/tools/search_notes.py:21`)

```python
search_notes(patient_id: str, section?: str, keyword?: str) -> str
```

**底层做了什么**

```
1. loader.all_notes() 取文书全表 (cols: 住院号 / 阶段 / 子阶段 / 内容)
2. 按 住院号 过滤本患者
3. 三种模式:
   - 无参 → 列出该患者所有"子阶段"目录 (例如: 入院记录, 术前讨论, 病程记录...)
   - section=X → 该子阶段全部文书 (限前 5 条, 每条限 500 字)
   - keyword=X → 全文搜, 限前 10 条
```

**调用示例**

```python
search_notes(patient_id="J19039")
# 返回:
# 文书目录 (共 8 个子阶段, 152 条记录):
#   术前讨论(12 条, 24,300 字符)
#   病程记录(38 条, 78,200 字符)
#   入院记录(2 条, 5,400 字符)
#   ...

search_notes(patient_id="J19039", section="入院记录")
# 返回前 5 条入院记录原文

search_notes(patient_id="J19039", keyword="人工报告")
# R191 用这个查"该次报告由第三方人工出具"的反证 (找到 = CLEAN)
```

**已知局限**

| 问题 | 影响 |
|------|------|
| 子阶段命名不统一, 不同医院/不同模板差异大 | section 参数不通用 |
| keyword 是 substring 匹配, 没有近义词 | 模板3 (口腔诊断 vs 大手术) 易漏检 |
| 没有时间维度 — 同次住院里 "术前 vs 术中" 无法区分 | C 类串换 (R040 骨折术间串换) 难判 |
| 每条限 500 字, 长文书被截 | D 类 (R285 心理治疗虚记) 需要原文细节才能判 |

### 2.4 note_diagnosis — 诊断提取

**接口** (`src/javert/tools/note_diagnosis.py:24`)

```python
note_diagnosis(patient_id: str) -> str
# 无可选参数, 一律返回该患者全部诊断 (按出现次数排序)
```

**底层做了什么**

```
1. 读 14 个诊断子阶段 (入院诊断/出院诊断/术前诊断/术后诊断/...)
2. 用正则 (数字编号 + 分号 + 换行) 拆分多诊断
3. Counter 统计每个诊断出现次数, 记录来源子阶段
4. 返回格式: "1. 「2 型糖尿病」 (出现 5 次, 来源: 入院诊断/出院诊断)"
```

**调用示例**

```python
note_diagnosis(patient_id="J19039")
# 返回:
# 从文书提取到 6 条诊断 (共匹配 7 个诊断子阶段):
# 1. 「脑干海绵状血管瘤」 (出现 5 次, 来源: 入院诊断/出院诊断/术前诊断)
# 2. 「高血压病 3 级」 (出现 3 次, 来源: 入院诊断/出院诊断)
# 3. 「2 型糖尿病」 (出现 2 次, 来源: 入院诊断)
# ...
```

**已知局限**

| 问题 | 影响 |
|------|------|
| 拆分基于符号/数字, 中文标点不规范的文书会拆错 | 诊断噪声多 |
| 没有 ICD 编码 (移除了 ICD enrich) | 模板2 (R151 非肝炎判断) 要 LLM 自己判断"是不是肝炎诊断" |
| 不区分 主诊断/合并诊断 | 模板3 (口腔诊断只见牙周炎) 准入条件难定 |

## 3. 三大可复用模板抽象

### 3.1 模板1 — 重复收费 / 内涵重叠 (R191 原型, 覆盖 A 类 28 条)

```yaml
# 模板伪 yaml
template_id: M1_overlap_billing
inputs:
  primary_fee_keywords: []     # 主项关键词, 例 R191: [PET-CT, 全身断层, SPECT 全身]
  attached_fee_keywords: []    # 附属项关键词, 例 R191: [图文报告, 人工报告, 报告费]
  required_diagnosis: []       # 可选, 限制规则只对某种诊断的患者生效
  note_negative_keywords: []   # 文书反证关键词, 例 R191: [第三方报告, 外送]
logic: |
  IF search_fees 中同时命中 primary AND attached
     AND (required_diagnosis 为空 OR note_diagnosis 命中)
     AND search_notes(keyword=attached) 中无 note_negative_keywords
  THEN VIOLATION
  IF primary 单独存在 (无 attached): CLEAN
  IF 都没有: CLEAN (规则不适用)
  IF 信息模糊: INCONCLUSIVE
```

**A 类 28 条往这个模板填的速查**

| Rule | primary | attached |
|------|---------|----------|
| R045 | 肩锁关节脱位切开复位内固定术 | 韧带重建术 |
| R047 | 关节镜下半月板修整 / 韧带重建 / 骨折复位 / 滑膜切除 | 关节镜加收 |

## 5. 各 tier 详解

### 5.1 A 类深读: 哪几条最适合先做

把 A 类 28 条按"工具命中难度"再细分:

**A1 (易, 同次住院两笔费用名字直接对得上, ~10 条)**:
R045, R047, R077, R112, R118, R119, R191, R208, R260, R300

**A2 (中, 需要文书反证, ~10 条)**:
R069, R105, R115, R116, R117, R185, R226, R228, R292, R295

**A3 (难, 涉及时长/频次比对, ~8 条)**:
R018, R054, R205, R227, R296, R303, R304, R305

> **推荐 pilot 先做 A1 的 6 条**: R045, R047, R077, R112, R191(已), R208 — 都是骨科/影像/麻醉/血液净化, 不会卡在精神科领域知识上, 也不依赖时长.

### 5.2 B 类深读: 检验类是甜区, 麻醉类需要"双工具"

B 类 28 条里:
- **B-检验 (R141-R162)** 共 11 条都是同一模式: 一个标志物 + 它的合理诊断指征. 11 条 yaml 长得几乎一样, 只是 `exam_keywords` / `indication_diagnoses` 不同. **模板2 极佳样板**.
- **B-影像 (R108-R132)** 共 6 条, 大多是常规检查无指征普查. 难点: "无指征"的判定需要 LLM 阅读诊断 + 病史, 比 B-检验更主观.
- **B-麻醉 (R218-R225)** 需要联合 search_fees(药品类) 查"是否用了肌松药 / 是否全麻", 一次工具调用不够.
- **B-内分泌 (R278-R279)** 对甲状腺患者**强相关**, 应该进 pilot.
- **B-精神科 (R311-R313)** 难度同麻醉.

> **推荐 pilot 先做 B 类的 5 条**: R151, R141, R153, R278, R279 — 全是检验/内分泌, 对甲状腺患者有合理命中率.

### 5.3 G 类深读: 不进甲状腺 pilot

17 条对甲状腺患者**几乎零命中**. 应该:
- v0.2 留位置但不批跑 (status=drafting, 跳过)
- v0.3 切换到口腔患者群体时, 17 条 yaml 一次性写完 (模板3 + 关键词数组替换)

### 5.4 C 类深读: 检验方法串换是死区

R170-R180 (11 条) 都是 "X 方法做 Y 测定, 按 Z 方法收费". 这种**费用名通常不写方法**, 工具看不出来. 建议直接归 N/A.

剩下的 25 条 C 类是 "做了 X 手术 / 治疗, 按 Y 手术 / 治疗收费". 这种**需要看手术记录文书**, 但医保监管的实际飞检中, 这一类的核心证据是术中视频 + 耗材使用记录, 不是文书 — 单纯靠文书的精度天然有限.

> **推荐 pilot C 类先不做**, 等 v0.3 看 A+B 模板稳了再回头.

### 5.5 D 类深读: "未开展但收费" 的本质

R015 / R037 / R070 / R080 / R103 / R134 / R203 / R224 这 8 条都是同一句话: "未开展相关诊疗项目, 但收取对应诊疗费用" — 各 domain 一条. 模板逻辑:

```
逻辑: 看 fee 项目名 → 查文书是否有对应操作记录
难点: 项目名 ↔ 文书表述不一致 (例如 "深度静脉穿刺" 在文书叫 "深静脉置管"),
      LLM 要做语义对照, 这个不难, 但 trigger_keywords 列表得每条 domain 配一份
```

> **推荐 pilot D 类先做 1 条 R285** (精神科未实施心理治疗却计费), 因为心理治疗在文书里有专门子阶段, 信号清晰. 其他 8 条等 D 模板成型再批量.

### 5.6 E 类深读: 一个新 change 的范围

E 类 19 条都因为 "我们不知道诊疗目录里这个项目应该怎么计价". 解锁路径:

```
add-catalog-loader change:
  - 数据源: 各省《医疗服务诊疗目录》 (上海/福建已公开 CSV)
  - 工具: catalog_lookup(item_name) → {标准计价单位, 加收规则, 内涵说明}
  - 影响规则: E 类 19 条 + 部分 D 类 + 部分 C 类
```

不在 bootstrap-javert-mvp 范围内, 应该作为下一个 change 提议.

### 5.7 F 类深读: 多数注定不可审

F 类 17 条里:
- **跨患者比对类 (5 条)**: R281, R283, R289, R290 — 单病历看不出, 但跨 50 患者批量看可以. 例如 R289 量表评定造假 = 多人量表数值高度雷同, 这个用"批跑后做异常检测"能做.
- **机构属性类 (4 条)**: R005, R036, R082, R212, R314, R315 — 单病历完全看不出, 需要 HR / 财务 / 合同数据.
- **笔迹/原始数据类 (4 条)**: R006, R287, R288, R290 — 文书电子化后, 笔迹证据丢失.
- **行为类 (4 条)**: R001, R002, R280, R282 — 患者+医院间的关系, 需要外部调查.

> **推荐 F 类全部标 N/A**, 但记录在册. 跨患者比对类可以作为 v0.4 `add-cross-patient-stats` change 的对象.

template: M1_overlap_billing       # 新增字段

violation_type: 重复收费
question: 开展肩锁关节脱位切开复位内固定术, 重复收取韧带重建术费用.

# Javert 单卡产能基线 — Qwen3.6 + cuda graph（预估版）

> 2026-07-17 · 状态：**预估，未批测**。依据两组实测数据折算；下次在 62 跑 ≥10 人批测后用实测值替换本文数字。

## 实测依据

| 项 | 值 | 来源 |
|----|----|------|
| 旧基线吞吐 | 5.6 人/时·卡（~11 分钟/人） | 50 人批实测，Qwen3.5-35B，规则内并发 5，单张 RTX 5880 Ada 48G |
| 旧 decode 速度 | ~15 tok/s | 62 sglang，cuda graph 开启前 |
| 新 decode 速度 | **110–120 tok/s** | 62 sglang 实测，Qwen3.6-35B-A3B-FP8 + cuda graph（已固化到 `~/launch_qwen3.6.sh`） |

## 折算

- decode 提速 ≈ 8×；并发 5 路共享 GPU 打不满单流速度，**保守按 4× 有效提速**计。
- LLM 生成占单患者墙钟时间绝大头，其余（检索/规则引擎/IO）不随卡变。

| 指标 | 旧实测 (Qwen3.5) | 新预估 (Qwen3.6+cg) |
|------|------------------|---------------------|
| 单患者耗时 | ~11 分钟 | **~3 分钟** |
| 出院吞吐 / 卡 | 5.6 人/时 | **~20 人/时** |
| 出院产能 / 卡·8h | 45 人 | **~160 人** |
| 门诊产能 / 卡·8h（按住院 1/5 数据量估） | ~190 例 | **~650 例** |

## 算力公式

```
所需 5880 Ada 卡数 = ⌈ 日出院数/160 + 日门诊数/650 ⌉
```

示例（顶级三甲肿瘤内科，浙大一级）：130 出院 + 500 门诊 → 0.81 + 0.77 ≈ 1.6 → **2 张卡**。

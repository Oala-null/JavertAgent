核心需求

R020 经血管介入项目, 扩张多支血管超出计价标准 心血管内科 · 超标准收费

📜 规则原文

🔴 缺什么

  • 项目编码 + 名称 (PTCA / STENT / ELCA / 旋磨术 等)
  • "每支血管" / "每增加一根血管加收 X%" 等加成条款

R279 甲功三项/五项 普查 内分泌 · 过度检查

📜 规则原文

为住院患者无指征普遍开展"甲状腺功能三项"或"甲状腺功能五项"检查并收费.

💡 示例

某医院为患者开展入院检查时, 未依据患者病情, 无指征为住院患者普遍开展"甲状腺功能三项"或"甲状腺功能五项"检查并收费.

🟢 现有工具能审吗

能, 但有 pilot caveat:
  • search_fees(keyword="甲功" / "FT3" / "FT4" / "TSH") 看 fee 命中
  • note_diagnosis 查甲状腺相关诊断

⚠️ 重要 pilot 注意

对甲状腺 pilot 50 患者绝大多数有指征 (CLEAN), 该规则应主要用于非甲状腺患者群体. 装好 prompt 但 priority 应标低, 等数据集切换后再用.

🟡 同事可提供 (可选)

甲功检查指征清单 (内分泌科):
  • 甲状腺相关疾病 (甲亢/甲减/甲状腺癌/结节/炎)
  • 心律失常 (尤其房颤, 排查甲亢)
  • 不明原因体重突变 / 怕冷怕热
  • 月经紊乱 (排查甲减)
  • 易激动 / 情绪波动
  • 甲状腺手术后随访
